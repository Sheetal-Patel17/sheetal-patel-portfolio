## ✨ Features

- 🌗 **Dark / Light Mode** toggle
- 🎬 **Cinematic loading screen** with terminal animation
- ⌨️ **Typewriter effect** for roles in Hero section
- 🔢 **Animated counters** for stats
- 🔍 **Filterable skills grid** with professional SVG icons
- 📱 **Fully responsive** — mobile, tablet & desktop
- 🎯 **Smooth scroll** navigation
- 💫 **Framer Motion animations** on scroll
- 📬 **Contact form** with success state
- 🏆 **Certifications** section
- 📅 **Journey / Timeline** section
- 🚀 **Deployed on Netlify** with CI-ready build

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or above)
- npm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Sheetal-Patel17/sheetal-patel-portfolio.git

# 2. Navigate into the folder
cd sheetal-patel-portfolio

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Build for Production

```bash
npm run build
```

The output will be in the `dist/` folder — ready to deploy on Netlify, Vercel, or GitHub Pages.
