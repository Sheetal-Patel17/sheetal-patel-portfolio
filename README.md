# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Sheetal-Patel17/sheetal-patel-portfolio.git
```

Go to project folder:

```bash
cd sheetal-patel-portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
